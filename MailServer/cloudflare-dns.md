# Cloudflare DNS — `nightvaults.com` for Stalwart

Replace `<PUBLIC_SERVER_IP>` with the public IPv4 address of the Windows server running Stalwart.

| Type | Name | Content / Target | Priority | Proxy |
|---|---|---|---:|---|
| A | `mail` | `<PUBLIC_SERVER_IP>` | — | **DNS only** |
| MX | `@` | `mail.nightvaults.com` | `10` | DNS only |
| TXT | `@` | `v=spf1 ip4:<PUBLIC_SERVER_IP> -all` | — | DNS only |
| TXT | `_dmarc` | `v=DMARC1; p=quarantine; adkim=s; aspf=s; rua=mailto:admin@nightvaults.com` | — | DNS only |

## DKIM

During the Stalwart setup wizard, leave **Generate email signing keys** enabled. After the domain is created, Stalwart can show the DNS zone data and DKIM public key for `nightvaults.com`. Publish the generated DKIM TXT record exactly as Stalwart provides it.

Do **not** put a DKIM private key in GitHub.

Stalwart supports both manual DNS management and provider integrations. This project deliberately uses **Manual DNS Server Management** so Cloudflare remains under your control. citeturn339983search4turn339983search6

## MTA-STS / TLS-RPT / client autoconfiguration

After HTTPS is working for `mail.nightvaults.com`, publish the additional MTA-STS, TLS-RPT, SRV, autoconfig and autodiscover records generated by Stalwart as appropriate. Stalwart can generate a complete DNS zone file for manual publication. citeturn339983search11turn339983search3

## Cloudflare proxy setting

`mail.nightvaults.com` must remain **DNS only** (gray cloud). Do not orange-cloud the mail hostname. SMTP and IMAP are not normal Cloudflare-proxied HTTP traffic.

Do not enable Cloudflare Email Routing for `nightvaults.com` while Stalwart is the authoritative inbound mail server. The MX record should continue pointing directly to `mail.nightvaults.com`.

## Reverse DNS / PTR

Set the public server IP's reverse DNS/PTR to:

```text
mail.nightvaults.com
```

Cloudflare does not control PTR records for your server IP. The PTR must be configured through the hosting/VPS/ISP provider that owns the IP range.

## Important port note

The Stalwart bootstrap/admin listener uses TCP 8080 locally. Do **not** create a Cloudflare DNS record intended to expose `:8080` to the public Internet. Once production HTTPS is configured, use the public `mail.nightvaults.com` URL and disable the temporary HTTP recovery/bootstrap listener as recommended by Stalwart. citeturn440139search0
